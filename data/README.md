# Data Sources

`data/raw/` is excluded from version control (see `.gitignore`) because these files are third-party and too large to version. Download each dataset and place it under `data/raw/` exactly as shown below before running the notebooks.

## dunnhumby — The Complete Journey

- **Source:** [Kaggle — Dunnhumby - The Complete Journey](https://www.kaggle.com/datasets/frtgnn/dunnhumby-the-complete-journey) (Firat Gonen)
- **Used in:** Notebooks 01–05
- **Place at:** `data/raw/dunnhumby/` — 8 CSVs: `campaign_desc.csv`, `campaign_table.csv`, `causal_data.csv`, `coupon.csv`, `coupon_redempt.csv`, `hh_demographic.csv`, `product.csv`, `transaction_data.csv`

## eCommerce Events History in Cosmetics Shop

- **Source:** [Kaggle — eCommerce Events History in Cosmetics Shop](https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop) (Michael Kechinov, REES46 Marketing Platform); download the November 2019 file only
- **Used in:** Notebook 06
- **Place at:** `data/raw/eCommerce Events History in Cosmetics Shop/2019-Nov.csv`

## Kevin Hillstrom — MineThatData E-Mail Analytics

- **Source:** [Kaggle — Kevin Hillstrom MineThatData E-MailAnalytics](https://www.kaggle.com/datasets/bofulee/kevin-hillstrom-minethatdata-e-mailanalytics) (Bofu Lee)
- **Used in:** Notebook 07
- **Place at:** `data/raw/Kevin Hillstrom MineThatData E-MailAnalytics/hillstrom.csv`
